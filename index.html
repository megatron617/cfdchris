Software Rendering Test Instructions

To test performance with software rendering (no GPU acceleration), launch your browser with the --disable-gpu flag. The --user-data-dir flag creates a temporary profile to avoid affecting your main browser.

Windows — Chrome

chrome.exe --disable-gpu --user-data-dir="%TEMP%\chrome-no-gpu"

Windows — Edge

msedge.exe --disable-gpu --user-data-dir="%TEMP%\edge-no-gpu"

macOS — Chrome

/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --disable-gpu --user-data-dir=/tmp/chrome-no-gpu

⚠️ Important Notes

  • Software rendering will be significantly slower
  • The temporary profile leaves your regular profile unchanged
  • The performance dashboard will detect which mode is active

Verifying Rendering Mode

Open the Performance Dashboard → System Info → "Rendering Mode". It shows HARDWARE or SOFTWARE.

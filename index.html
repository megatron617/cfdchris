Software Rendering Test Instructions

To test performance with software rendering (no GPU acceleration), you need to launch your browser with the --disable-gpu flag. The --user-data-dir flag creates a temporary profile to avoid affecting your main browser.

Windows - Chrome

chrome.exe --disable-gpu --user-data-dir="%TEMP%\chrome-no-gpu"

Run this in Command Prompt or PowerShell from the Chrome installation directory.

Windows - Edge

msedge.exe --disable-gpu --user-data-dir="%TEMP%\edge-no-gpu"

Run this in Command Prompt or PowerShell from the Edge installation directory.

macOS - Chrome

/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --disable-gpu --user-data-dir=/tmp/chrome-no-gpu

Run this in Terminal.

Linux - Chrome

google-chrome --disable-gpu --user-data-dir=/tmp/chrome-no-gpu

Run this in your terminal. Command may vary (try chromium-browser or chromium).

Firefox - All Platforms

Firefox uses different rendering paths. To test software rendering:

  1. Type about:config in the address bar
  2. Search for webgl.disable-angle and set to true
  3. Search for gfx.webrender.software and set to true
  4. Restart Firefox
Remember to revert these settings after testing.

⚠️ Important Notes

  • Software rendering will be significantly slower than GPU-accelerated rendering
  • The temporary profile ensures your regular browser profile remains unchanged
  • Navigate to this page after launching the browser with these flags
  • The performance dashboard will automatically detect which mode is active
  • Close the special browser instance when done testing

Verifying Rendering Mode

Open the Performance Dashboard and check the "System Info" section. The "Rendering Mode" field will show either HARDWARE or SOFTWARE.
